**Team:** May Ahmed Mourad (G12) · Shamsa Faris Almazrouei (G12) · Fatima Mohamed Almazrouei (G11) — ADNOC Schools, Madinat Zayed
**Competition:** Abu Dhabi University 6th Annual COE STEM Programming with AI Competition, theme *AI for Family*, Cycle 3
**Date:** 28 October 2026

## 1. Summary

AI was used in four ways: (1) to **build** the prototype (code, tests, documentation, deployment files), (2) as a **runtime feature** (Gemini turns a typed sentence into a proposed event that a person must confirm), (3) to **plan and draft prompts** (ChatGPT), and (4) to **produce the submission materials** (slide deck, technical report, video production pack and footage). The team directed the work, supplied the competition brief and accounts, made the project decisions and reviewed the results. Every statement of fact in the deck and report is tied to a recorded run, and the limits of that evidence are stated.

## 4. Human direction and oversight

- The team supplied the competition brief, decided to make the repository public and to host the API on Render, created the accounts and the Gemini key, and reviewed the deck before moving on.
- Safety by design: the language model only *proposes* an event; every event starts unconfirmed; deterministic code resolves names and times; the CP-SAT optimizer finds assignments; an independent verifier checks them; a person approves. When no valid plan exists the system reports the task as uncovered instead of inventing an assignee.
- Honest reporting: the report states that greedy first-fit ties DOMINO on critical coverage, that 5 of 51 benchmark cases were not run, that the rule parser’s held-out score is not independent, and that no study with families was done.

## 5. Errors found and corrected

AI-written work contained mistakes, found by review or live testing and then fixed: an unfair baseline comparison (the greedy baseline ignored user rejections); a React Flow fit-view that did nothing; an alias “car” matching two resources; `GEMINI_MODEL` set to a project id (now detected and reported); provider errors misread as rate limits; a navigation race after a hosted household loaded; a scenario clock shown but not sent; a wrong source cited for the 2-second solver target in the evidence ledger; and, while recording the video, an approval dialog that opened in the top-left corner (fixed on 28 Oct 2026, commit `379d09a`). The repository README, `AI_DEVELOPMENT_LOG.md`, `TESTING.md` and `docs/DEPLOYMENT.md` had statements that predated the live Gemini tests (and the README had garbled dash characters); all were updated on 28 Oct 2026.

## 6. Data and privacy

Only fictional household data is used; nothing about real families is stored or sent. Only fictional household text is sent to Gemini. The API key exists only in the server’s environment settings, never in the browser code, the repository, the deck, the report or the video; the published JavaScript was scanned for key patterns. Private account identifiers were kept out of every deliverable. *Action for the team: the shared ChatGPT link shows a Google project identifier and number in plain text, so delete the share link or remove that message before submission.*

## 9. Limits of AI use

AI output can be wrong. Natural-language extraction needs human confirmation; recovery plans are checked only against the rules the model declares; no claim is made about real-world safety or wellbeing outcomes. All results come from fictional households and one simulated day.
